# Frontend (Next.js)

The App Router shows the paginated frame inventory, version history, and DELTA
imports. Frame history links to the durable import job summary, which remains
available after row diagnostics expire.

Apollo Client sends browser GraphQL requests to the same-origin `/api/graphql` route.
Set `BFF_URL` to the BFF origin or full GraphQL URL. It defaults to
`http://127.0.0.1:4000` and Compose uses `http://bff:4000`. The existing
`/api/:path*` fallback forwards requests such as health checks to
`BACKEND_URL` (default `http://localhost:8080`).

## GraphQL operations

Use Node.js 22.18 or newer for code generation. Keep operations in `.graphql`
files under `src/`. Run `npm run codegen` after changing an operation or the
BFF schema. Codegen reads `../bff/schema/*.gql` from the checkout, so it can
run without a running BFF. Include `src/generated/graphql.ts` when committing
schema or operation changes. Run `npm run codegen:check` to verify that the
generated documents are current.

## Local development

Run `npm ci` and `npm run dev` from `src/frontend`. For local imports, run
Spring Boot and the BFF on the host and enable their local import settings.
Start the frontend with `npm run dev -- --hostname 127.0.0.1` for this flow.
See the [backend README](../backend/README.md) and [BFF README](../bff/README.md).
In **Imports**, enter the local operator token and select the CSV file.
The browser sends the file directly to the S3 URL with the signed headers.
Keep the frontend origin in the upload bucket's CORS configuration.

The frontend keeps the operator token in memory for this session. To reopen an
import, use its job ID or select the import link in a frame's version history.
Run `npm run lint` and `npm run build` to verify the frontend.

## Verify a DELTA import in the browser

Set `INVENTORY_IMPORT_LOCAL_TOKEN` in the repository root's `.env` to a value
generated by `openssl rand -hex 32`. From the repository root, start the local
stack with imports enabled.

```sh
docker compose up -d --build --wait
```

Use an empty local database for the counts below. Compose reuses its existing
database volume, so on a stack with inventory the first upload counts may vary.

1. Open **Imports** at <http://127.0.0.1:3000>. Enter the local operator token
   and upload [`inventory_frame.csv`](../../data/inventory_frame.csv).
   The completed job should show 1,000 applied and zero rejected.
2. Upload the same file again. The second job should show 1,000 unchanged
   and zero applied.
3. Open **Frames** and view an imported frame's version history. Its import job
   link should open the first job.
4. In a copy of the CSV, keep the header and one data row. Change that row's
   `status` to `INVALID` and upload the copy. The job should complete with one
   rejected row. **View row errors** should identify the invalid status.

For more cases, use the [test CSVs](../../data/import-cases/README.md) and their
expected results.
